# Forms Dimensionador

Suplemento do Excel para consultar e atualizar registros de uma tabela por formulário. Versão de teste de instalação.

- Painel: https://brunosantos29.github.io/forms-dimensionador/taskpane.html
- Manifesto: `manifest.xml` (carregar no Excel em Suplementos > Carregar Meu Suplemento)

O painel roda 4 testes: conexão com o Excel, leitura, gravação numa aba à parte e gravação de configuração no arquivo.
